# Claude Design System Principles & Minimalist UI Guidelines

*Based on Anthropic Claude Design Architecture*

## Core Principles

1. **Radical Minimalism & Restraint**
   - Less is more. Every element must earn its place.
   - Avoid data slop: strip away unneeded icons, debuggers, raw developer metrics, and technical jargon.
   - Generous whitespace and intentional visual rhythm.

2. **Humane, Senior-Friendly & Accessible**
   - Clean, large typography with high contrast.
   - Warm, reassuring, plain-English explanations.
   - Instant visual clarity: green (mild/home care), yellow (moderate/doctor consult), red (emergency/911).

3. **Zero Technical Clutter on Frontend**
   - Background intelligence (RAG, Firecrawl web research, BM25 indexing) operates silently and seamlessly under the hood.
   - No raw API keys, endpoint configurations, or developer debug consoles exposed to patients.

4. **Typography & Spatial Hierarchy**
   - Refined font hierarchy with high legibility.
   - Card surfaces with subtle borders and gentle elevation.
   - Natural mobile and desktop responsive layout.
